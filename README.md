# Cirius — визовый консалтинг

Сайт-визитка компании «Сириус» (Cirius Consulting): помощь с шенгенской визой, Ташкент.

- Две страницы: `index.html` (главная) и `services.html` (услуги и цены).
- Только HTML, CSS и JavaScript: без бэкенда, базы данных, форм и сборки.
- Светлая и тёмная тема, русский и английский язык.

## Как посмотреть
Открыть `index.html` в VS Code через расширение Live Server (кнопка «Go Live»).
Можно и просто двойным щелчком по `index.html`, но через Live Server сайт ведёт себя так же, как на хостинге.

## Публикация
Netlify как обычный статический сайт: публикуется папка целиком, ничего собирать не нужно.
Заголовки безопасности для Netlify — в файле `_headers`.
