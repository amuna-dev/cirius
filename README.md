# Cirius — визовый консалтинг

Сайт-визитка компании «Сириус» (Cirius Consulting): помощь с шенгенской визой, Ташкент.

- Две страницы: `index.html` (главная) и `services.html` (услуги и цены).
- HTML, CSS и JavaScript: без форм и базы данных.
- Светлая и тёмная тема, русский, узбекский и английский язык.
- Счётчик просмотров на главной: функция Netlify `netlify/functions/views.mjs` + Netlify Blobs.

## Как посмотреть
Открыть `index.html` в VS Code через расширение Live Server (кнопка «Go Live»).
Можно и просто двойным щелчком по `index.html`, но через Live Server сайт ведёт себя так же, как на хостинге.

## Публикация
Netlify, через подключение репозитория GitHub. Все настройки уже в `netlify.toml`:
Netlify сам скопирует файлы сайта в папку `dist`, опубликует её и подключит функцию счётчика.
Вручную в панели Netlify ничего указывать не нужно. Хранилище Netlify Blobs создаётся само.

Заголовки безопасности для Netlify — в файле `_headers`.

Локально (Live Server) функции нет, поэтому счётчик просмотров скрыт — это нормально.
