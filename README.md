# Cirius Visa — визовый консалтинг

Сайт-визитка компании Cirius Visa: помощь с шенгенской визой, Ташкент.

- Две страницы: `index.html` (главная) и `services.html` (услуги и цены).
- HTML, CSS и JavaScript: без форм и базы данных.
- Светлая и тёмная тема, русский, узбекский и английский язык.
- Счётчик просмотров в шапке: функция Cloudflare Pages `functions/api/views.js` + база Cloudflare D1.

## Как посмотреть
Открыть `index.html` в VS Code через расширение Live Server (кнопка «Go Live»).
Можно и просто двойным щелчком по `index.html`, но через Live Server сайт ведёт себя так же, как на хостинге.

## Публикация
Cloudflare Pages, через подключение репозитория GitHub: каждый push в `main` обновляет сайт.
- Команда сборки: `npm run build` — только копирует файлы сайта в папку `dist`.
- Папка публикации: `dist`.
- Функция счётчика (`functions/api/views.js`) и база D1 подключаются по `wrangler.toml`.
- Заголовки безопасности — в файле `_headers`.

Файлы `netlify.toml` и `netlify/functions/` — от прежнего хостинга Netlify.

Локально (Live Server) функции нет, поэтому счётчик просмотров скрыт — это нормально.
