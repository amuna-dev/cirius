# Сириус — визовый консалтинг

Двухстраничный сайт-визитка компании «Сириус» (помощь с шенгенской визой, Ташкент).
Статический HTML, CSS и JS без зависимостей, без форм и сбора данных.
Светлая и тёмная тема, русский и английский язык.

Запуск: `python -m http.server 8000` и открыть http://localhost:8000
